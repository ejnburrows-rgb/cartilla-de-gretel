# Branch rules — La Cartilla de Gretel

This file is the source of truth for branches. Agents do not rely on memory.
If this file and a chat message disagree, this file wins.

## The main copy
- `main` is the live book. No agent works directly in `main`.
- Nothing goes into `main` without the owner's explicit yes for that exact change.

## The only allowed working copies (branches)
Use ONLY these. Do not create a new branch for a new task.

1. `work/artwork` — pictures only. Never redraw, recolor, or replace a picture without the owner's yes naming that exact picture.
2. `work/lessons` — lesson pages and curriculum only.
3. `work/games` — games only.
4. `work/teacher` — teacher pages only. Only fix what a teacher actually opens.
5. `work/tests-only` — tests and checks only. Nothing visible changes here.

That is 5 working copies plus `main`. That is the whole set.

## How work goes in
- Pick the one copy that matches the job. All work on that job goes in that same copy.
- One job at a time in a copy. Finish it, get the owner's yes, move it into `main`, then start the next job in the same copy.
- If a job needs two copies (for example, a lesson and its game), say so first and wait for the owner's yes naming both copies.
- Never start a new copy because a task feels big, because another copy is busy, or because it is easier.

## What is forbidden
- No new branch names. No branch per task, per agent, per day, or per try.
- No work in `main`. No deleting, renaming, or merging without the owner's yes naming the exact thing.
- A draft that has not been touched for 14 days gets listed for the owner as keep or drop. It is not deleted by an agent on its own.

## For a new project
Start with `main` plus at most 3 working copies, named by area (for example: artwork, lessons, teacher).
Add a new working copy only when the owner says yes and names it in his own words. Add it to this file in the same change.

## If you are an agent reading this
Read this file first. Work only in the copy listed above for your job. If your job does not fit one copy, stop and ask the owner — do not invent a new copy.
