## Important distinctions

- **Plain or uncolored drawings may still be marked “optimized version exists” by machine evidence.** Owner visual approval of finish and coloring is a separate decision. Review these explicitly.
- **File exists ≠ optimized and colored ≠ approved ≠ used on the correct page.** Current mapped file paths are shown where identified, but page rendering has not been browser-certified.
- “Not linked in 330 placements” **does not mean unused** throughout the app. Original scans, faithful masters, resizing derivatives and backgrounds must not be deleted based on names or this index.
- The 202 groups are a working drawing count, not a final count of distinct original illustrations. The original 330 placement references are all included.
- Background and owner-intake assets have distinct purpose, which can be reviewed without marking them as unnecessary.
