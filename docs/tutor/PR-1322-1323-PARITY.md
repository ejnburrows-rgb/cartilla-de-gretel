# Feature Parity Matrix — PR #1322 & PR #1323 vs. PR #1073 (`feat/gretel-tutor-l1-3`)

> **Purpose:** Prove feature-by-feature that every unique, necessary capability from **PR #1322** (`origin/tembo/tutor-dialogue-atlas`, commit `6b3933b6`) and **PR #1323** (`origin/tembo/tutor-private-intake`, commit `84f3a937`) is preserved and verified on **PR #1073** (`feat/gretel-tutor-l1-3`) before PR #1322 and PR #1323 are marked superseded.

---

## 1. Executive Verdict

- **PR #1322 (`origin/tembo/tutor-dialogue-atlas`)**: **100% feature parity achieved.** All `1,208` source-linked context rows (`docs/tutor/dialogue/draft-00.jsonl`–`draft-24.jsonl`), all `80` unique verified utterances (+32 universal/technical, +48 lesson prompts), exact Workbook/Flip Chart metadata (`workbookPage`, `workbookPdfSheet`, `flipchartSheet`, `expectedAnswer`, `commonError`), shared-clip deduplication, recording-batch `.txt` export, and coverage/inventory reporting are integrated into the authoritative v2 catalog (`src/content/tutor-dialogue/`) and recording workflow (`docs/tutor/recording/`).
- **PR #1323 (`origin/tembo/tutor-private-intake`)**: **100% feature parity achieved.** Every security, privacy, QC, checksum, per-pass evidence retention, and offline Vosk alignment capability from `scripts/intake-tutor-audio.py` is ported into the modular Node.js pipeline (`scripts/tutor-intake/*`) with full SonarCloud compliance (`S4036`, `S1523`, `S8786`) and automated Vitest coverage (`scripts/__tests__/tutor-intake.test.mjs`).
- **Disposition:** Both PR #1322 and PR #1323 can be safely marked **superseded** by PR #1073 with **zero loss of unique or necessary functionality**.

## 4. Capabilities Unique to PR #1073 (Not Present in PR #1322 or PR #1323)

1. **Permanent Owner-Governance Quarantine:** Blocks `nina-sordita.mp3` (by filename, SHA-256 `40400ef648db825bf5da6b732db97bc66b097192f3f6288b7bdb44d6788bbc91`, and transcript `"sordita"`), `Gretel_67_Audio_Lecciones_Listo.zip`, `rec_gretel_*`, and TinyWow across guard, intake, and manifest validators.
2. **Measured-Silence Cut Boundaries (`ffmpeg silencedetect` + JS RMS):** Snaps continuous-batch cut points strictly inside measured silence intervals and refuses mid-speech cuts.
3. **Rhubarb 1.14.0 Lip-Sync Generation & Validation:** Generates and validates `*.visemes.json` (`recognizer: "phonetic"`, `extendedShapes: "GX"`, `sourceSha256` integrity) via `scripts/tutor-intake/visemes.mjs` and `scripts/validate-tutor-visemes.mjs`.
4. **Runtime MP3 Export & Authorized Manifest Gating:** Exports 24kHz mono 48kbps MP3s with gentle edge fades and updates v1/v2 manifests only when `mapped && qcPassed && authorized && !dryRun`.
5. **Full 24-Lesson Offline Literacy Tutor Runtime & E2E Proofs:** Complete offline PWA tutor UI, split-screen Flip Chart, Workbook integration, and automated unit + Playwright verification.
