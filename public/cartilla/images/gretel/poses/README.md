# Gretel animation frames

Drop the Gretel motion frames in THIS folder. Keep the file names exactly as-is.

The app flips through these frames to animate Gretel like a cartoon.

Expected files (.webp):

- pose7-talk-0.webp
- pose7-talk-1.webp
- pose7-talk-2.webp
- pose7-wave-0.webp
- pose7-wave-1.webp
- pose7-wave-2.webp
- pose7-cheer-0.webp
- pose7-cheer-1.webp
- pose7-blink.webp

If this folder is empty or a frame is missing, the app automatically shows a
still image instead, so nothing ever breaks.
